# Приёмка проекта

Обезличенный отчёт реальной проверки FilmCraft 0.20.1 находится в `tests/results/baseline-v0.20.1.json`; изображения — в `tests/baseline/`. Он подтверждает только перечисленные там сценарии и не заменяет локальные тесты.

## Статическая проверка

```sh
python3 scripts/check_project.py
```

Проверяются Python/Bash syntax, JSON/TOML, автотесты конфигуратора, целостность всех upstream-файлов по SHA-256, обязательные правила и отсутствие встроенного token. Отдельно автотесты запускаются командой `python3 tests/test_configurator.py`.

## Headless

```sh
bash scripts/smoke-headless.sh
```

Pass означает, что на текущей установке выполнены:

- MCP initialize по протоколу 2025-06-18;
- получены tools и оба ресурса;
- demo project и active sequence прочитаны;
- `timeline.razor` найден в живом каталоге;
- выполнен обратимый cut и вызван undo;
- PNG декодирован из image content;
- записан H.264 640×360 из видимого диапазона 1,0–1,5 с;
- `offlineMedia` пуст;
- файл проверен ffprobe, полным decode и RGB-анализом нечёрного кадра из середины.

## Bridge

```sh
bash scripts/smoke-bridge.sh
```

Pass означает, что на изолированном demo получены UI state, automation elements и window screenshot. Пользовательский проект не открывается и не изменяется.

## Клиентская матрица

Для каждого нужного клиента выполни read-only probe, затем контролируемый demo cut с подтверждением записи и undo. Проверь отображение или сохранение PNG. Не помечай клиент полностью совместимым только по успешному подключению.

## Реальный проект

После demo выполни пилот на небольшой копии: import → place → cut → visual check → save copy → export → verify. Только после него можно говорить о готовности конкретной машины к реальной работе.

## Границы проверки

Static validation не заменяет MCP. Headless не проверяет desktop. Bridge smoke не проверяет все команды, кодеки и целевые NLE. Отчёты должны разделять эти уровни и не объявлять весь функционал FilmCraft проверенным.
