# Происхождение материалов

## Официальный источник

- Репозиторий: `https://github.com/storytold/filmcraft`.
- Зафиксированный релиз: `v0.20.1`.
- Commit: `cedf0c9bd060eb06a977d532402be2097c9ebe42`.
- Release published: `2026-11-12T00:26:09Z`.

Первоначальный `references/upstream/` содержит официальные `docs/`, README, ROADMAP, SECURITY, NOTICE и лицензии из этого тега. Полный перечень, URL, размер и SHA-256 каждого файла находится в `references/upstream-manifest.json`. После локального обновления актуальные версия и происхождение определяются манифестом, а не этой начальной записью. Проверка: `python3 scripts/check_project.py`.

Официальный `.mcp.json` сохранён как `references/upstream/mcp.source.json`; он предназначен для source build и не используется как готовая локальная конфигурация. `references/commands-v0.20.1.json` — снимок из 718 команд, полученный запуском проверенного официального Linux-бинарника v0.20.1; он не подменяет локальный command dump.

## Правила и сценарии проекта

`AGENTS.md`, `SKILL.md`, адаптеры и scripts созданы для этого переносимого проекта. Это не официальные файлы ArtCraft и не замена upstream-документации.

Рецепты в `references/recipes.md` основаны на официальных docs и server tests v0.20.1. Фактические локальные результаты, если тесты запускались, сохраняются отдельно в `tests/results/*.local.json`; отсутствие такого файла означает, что локальная проверка ещё не выполнена.

## Community-материалы

Community skill и сторонние gist-файлы в комплект не включены. Старые машинно-зависимые пути, порты, количество команд и обходы ошибок не копировались.

## Context7

Context7 не скачивается и не входит в offline docs. Включён только необязательный шаблон MCP-подключения. Идентификатор библиотеки: `/storytold/filmcraft`.

## Обновление

По умолчанию `update-docs` получает файлы из официального GitHub-репозитория, сверяет commit релиза, вычисляет хэши и сохраняет предыдущую версию в `workspace/runtime/docs-backup/`. Для офлайн-зеркала можно явно передать доверенный `--repo` и ожидаемый полный `--commit`; зеркало не считается официальным источником автоматически. Обновление документов не означает автоматическую проверку совместимости: после него нужны живой command dump и smoke-тесты.
